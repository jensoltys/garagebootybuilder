# Getting help

- **Using the try-it page or your own copy?** Check the README first, then open an [issue](../../issues/new/choose) if something in the code looks broken. Copies are community-supported, and your log lives only in your own browser, so nobody can recover it for you. Save backups from the Progress tab.
- **Questions about training or your health?** Ask a doctor or a qualified coach. This app isn't medical advice.
- **Security problem?** See [SECURITY.md](SECURITY.md).
